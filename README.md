# FastAPI Practice

A beginner-friendly repository for practicing **FastAPI with Python**.

This repository contains my practice programs and examples while learning FastAPI concepts, REST APIs, Pydantic, and CRUD operations.

## 🛠️ Tech Stack

* Python
* FastAPI
* Pydantic
* Uvicorn

## ▶️ Run Locally

Clone the repository:

```bash
git clone https://github.com/your-username/FastAPI-Practice.git
```

Go to the project folder:

```bash
cd FastAPI-Practice
```

Install dependencies:

```bash
pip install fastapi uvicorn pydantic
```

Run the application:

```bash
uvicorn main:app --reload
```

Open the API:

```text
http://127.0.0.1:8000
```

## 📖 API Documentation

FastAPI provides automatic interactive documentation.

**Swagger UI:**

```text
http://127.0.0.1:8000/docs
```

**ReDoc:**

```text
http://127.0.0.1:8000/redoc
```
